## Назначение решения:
Локатор Событий — это мини-приложение для MAX и Django-сервис, помогающий пользователям находить ближайшие события в шаговой доступности, записываться на них и управлять заявками. Основная идея — объединить локальный досуг, UGC-организацию и автоматическую модерацию в одном простом сценарии: найти подходящее мероприятие рядом, подтвердить участие и получить уведомление в чате.

## Основной пользовательский сценарий:
Пользователь открывает чат-бот в MAX, выбирает кнопку «Найти досуг», после чего мини-приложение запрашивает геолокацию и показывает карту и ленту событий рядом. В интерфейсе можно просмотреть карточку мероприятия, проверить свободные места и нажать «Пойду». После этого сервис проверяет лимит мест, создаёт запись, и пользователь получает подтверждение в чат-боте с адресом, временем и ссылкой на билет. Организатор может создать событие через форму, после чего оно отправляется на модерацию и публикуется только после подтверждения администратора.

## Состав и архитектура решения:
Решение строится на стеке Django, Django REST Framework, PostgreSQL + PostGIS, React и MAX Bridge. На бэкенде реализованы авторизация через MAX initData, JWT, гео-фильтрация событий, бизнес-логика регистраций, уведомления в MAX и модерация через Django Admin. На фронтенде используется React с интерфейсом в стиле MAX UI и картой для гео-индексации. Данные и события хранятся в PostgreSQL/PostGIS, а контейнеризация выполняется через Docker Compose.

## Команда однострочного запуска:
docker compose up --build -d

## Порядок работы с тестовыми данными:
Для наполнения базы данными используется команда `python manage.py seed_data`. Она создаёт администраторскую учётную запись admin / admin_pass, тестового организатора test_organizer, а также наполняет базу 12–15 событиями в Тюмени и окрестностях, чтобы можно было сразу проверять сценарии карты, фильтрации и подачи событий на модерацию.

## Пошаговый сценарий проверки:
1. Открыть список событий через мини-приложение или API. Перейти в Django Admin по адресу /admin/ с логином admin и паролем admin_pass.
2. В панели администрирования открыть раздел «События», проверить созданные события со статусом pending и перевести одно из них в approved.
3. Вернуться в приложение, убедиться, что событие отобразилось на карте и в ленте, а также проверить возможность записи на событие и получения уведомления в чат-боте.
4. Для дальнейшей проверки использовать тестового организатора test_organizer и проверить сценарий создания события, модерации и записи участников.
